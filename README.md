# GoSlide — Landing Page for Premium Gaming Mouse

[Посмотреть Live Demo](https://irynaglytsko.github.io/GoSlide/)

Современный, адаптивный и высококонверсионный одностраничный сайт (Landing Page), созданный для демонстрации и продажи флагманской беспроводной игровой мыши **GoSlide**. Проект разработан с акцентом на высокую скорость загрузки, интерактивность, доступность и безупречный UI/UX-дизайн.

---

## 🚀 Описание проделанной работы

В рамках разработки проекта был выполнен полный цикл фронтенд-разработки: от анализа структуры макета до деплоя на хостинг. 

### Реализованный функционал:
*   **Интерактивный промо-блок:** Главный экран с ключевыми характеристиками ультралегкого девайса (вес 55г, разрешение до 20 000 DPI) и кнопкой просмотра видео.
*   **Динамическая интерактивная витрина:** Секция выбора цвета устройства, позволяющая пользователю переключать варианты исполнения (Black, Red, Yellow, Purple) со мгновенной сменой изображений.
*   **Секция детальных спецификаций:** Реализована подробная таблица технических характеристик (габариты, сенсор, частота опроса, энергоэффективность).
*   **Блок социальных доказательств:** Слайдер/карусель отзывов реальных клиентов с интеграцией рейтинга с Amazon.com.
*   **Экологический манифест:** Информационный блок, подчеркивающий использование переработанного пластика (Recycled Plastics) в производстве.

## 🛠 Технологический стек

При создании сайта использовались исключительно современные и чистые технологии без перегрузки проекта лишними тяжелыми фреймворками:

*   **HTML5:** Семантическая разметка для обеспечения правильной структуры документа, SEO-оптимизации и доступности (Accessibility).
*   **CSS3 (SCSS/Flexbox/Grid):** 
    *   Резиновая и адаптивная верстка (Mobile-First подход) для идеального отображения на смартфонах, планшетах и UltraWide-мониторах.
    *   Плавные CSS-переходы (transitions) и ключевые анимации (keyframes) для интерактивных элементов.
    *   Использование CSS-переменных для поддержки тем и удобного масштабирования стилей.
*   **JavaScript (ES6+):** 
    *   Реализация логики переключения цветовых схем продукта.
    *   Валидация форм/интерактивных элементов.
    *   Управление поведением карусели отзывов и мобильного меню (Toggle Menu).
*   **GitHub Pages:** Быстрый автоматический деплой и хостинг статического сайта напрямую из репозитория.

## 📈 Оптимизация и особенности UI/UX

*   **Адаптивность:** Сайт полностью оптимизирован под мобильные устройства. Меню трансформируется в удобный бургер на экранах с низким разрешением.
*   **Оптимизация графики:** Изображения оптимизированы под веб для обеспечения мгновенной отрисовки интерфейса (Core Web Vitals).
*   **Типографика и акценты:** Тщательно подобранный контраст шрифтов и CTA-элементов (Call to Action) для максимизации конверсии в покупку.

## 💻 Локальное развертывание

Чтобы запустить проект локально на своем компьютере, выполните следующие шаги:

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```

2. Перейдите в папку с проектом:
   ```bash
   cd GoSlide
   ```

3. Откройте файл `index.html` в любом современном браузере или используйте расширение вроде *Live Server* в VS Code.
